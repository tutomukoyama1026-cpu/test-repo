毎朝の報告のあとに入れ直します（中身は各担当のブランチの最新と同じ）。

| フォルダ | 担当 | 主な中身 |
|---|---|---|
| 01_社長 | 椙山改修：社長 | 朝の報告（最新・Todo 入り）・組織図・工程表修正提案（.html はブラウザで開く） |
| 02_図面計画書リスト | 図面・計画書リスト | YYMMDD_椙山食堂改修_図面・計画書リスト.xlsx |
| 03_課題リスト | 課題リスト | 課題リスト.xlsx・作業報告.md |
| 04_増減リスト | 増減リスト | 増減リスト.xlsx |
| 05_図面チェック | 図面チェック | チェック結果・実測データ一覧・点検口一覧 |
| 06_計画書チェック | 計画書チェック | 総合施工計画書チェック・施工計画書雛形（修正版） |
| 07_定例議事録 | 定例議事録 | 議事録・議事録様式 |
| 08_工程管理 | 工程管理 | 工程表.xlsx/.pdf・工程リンク.xlsx・整合チェック |
