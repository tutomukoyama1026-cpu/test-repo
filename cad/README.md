# ホウキ・モップ CADデータ

| ファイル | 内容 |
|---|---|
| `out/broom.step` / `out/mop.step` | 3Dモデル（部品ごとに色分けしたアセンブリ） |
| `out/broom.stl` / `out/mop.stl` | メッシュ（3Dプリント・ビューア用） |
| `out/broom.dxf` / `out/mop.dxf` | 2D外形図と主要寸法 |
| `out/*_preview.png` | プレビュー画像 |
| `build.py` | 寸法パラメータ（`B` / `M`）とモデル生成。`python build.py` で再生成 |
| `drawing.py` | DXF図面の生成 |
| `out/drawings.pdf` / `make_pdf.py` | 図面PDF（A3横・2枚）とその生成スクリプト |

## 主要寸法（mm）
**ホウキ**（写真1・2から実測）
- 全長 約876（グリップ端〜毛先）、グリップ端〜ヘッドの首 675
- パイプ φ18、フック付きグリップ φ24 × 85
- ヘッド角度 15°（斜めタイプ）、黄色ホルダー 幅225 × 高さ80 × 厚み20
- 毛の長さ 75、毛先の幅 約260、毛の厚み 24〜32

**モップ**（写真4から実測＋柄は想定）
- 赤ホルダー 幅210 × 奥行40 × 高さ17（中央の山形 幅85 × 高さ10）
- 糸の幅 190、厚み 35、長さ 280（想定）
- 柄（想定）：首振りジョイント + パイプ φ25 × 1200 + グリップ φ29 × 220 + 吊り穴付きキャップ
- 全高 約1563
