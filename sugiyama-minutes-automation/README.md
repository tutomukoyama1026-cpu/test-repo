# 椙山改修 定例会議 議事録自動化

Teams 定例会議 → 文字起こし → AI 要約 → 議事録フォーマット（Excel）へ自動記入 → Box 格納 → Box AI アシスタントが常に最新を回答

## 全体の流れ

```
①議題メール送信（議事録フォーマットに議題を記入して添付）
      │ フローA
      ▼
 Box 01_議題 に保存 ＋ 作業用として SharePoint にコピー
      
②Teams 定例会議（自動録音・文字起こし）
      │ フローB（会議終了から30分後に起動）
      ▼
 文字起こし取得 → Box 02_文字起こし
      │
 議題読み取り（readAgenda.ts）＋ 前回の未決事項（Box 04）
      │
 AI 要約（prompts/01_議事録作成プロンプト.md）→ JSON
      │
 議題ブックの「打合せ結果」欄へ記入（fillMinutes.ts）
      │
      ├─ Box 03_議事録 ／ YYYYMMDD_第NN回_議事録.xlsx（正式様式）
      ├─ Box 03_議事録 ／ YYYYMMDD_第NN回_要約.md（AI 用の本文）
      └─ Box 04_最新状況 ／ 最新_未決事項一覧.md（上書き。Box のバージョン履歴が残る）
      │
      ▼
 Teams チャネルに「議事録（案）」のリンクを投稿 → 担当者が確認・修正
      
③Box AI Hub「椙山改修 定例アシスタント」が 00・01・03・04 を自動で読み込み、質問に回答
```

**要点は、議題メールで送ったブックそのものに結果を書き込むこと。** 議題No が固定されているので、AI は「No.3 の結果」という単位で文字起こしを整理できます。表記揺れや議題の取りこぼしが起きにくく、様式も崩れません。

## Box フォルダ構成

```
/椙山改修/定例会議/
  00_運用マニュアル/   図面・計画書進捗確認 運用マニュアル
  01_議題/             20261002_第02回_議題.xlsx
  02_文字起こし/       20261002_第02回_文字起こし.vtt
  03_議事録/           20261002_第02回_議事録.xlsx ／ 20261002_第02回_要約.md
  04_最新状況/         最新_未決事項一覧.md
```

ファイル名は `YYYYMMDD_第NN回_種別` に統一します。回数は2桁にそろえると並び順が崩れません。

## 事前準備（最初に1回だけ）

### 1. Teams：会議を自動で録音・文字起こしする
定例会議の予定を開き、**会議のオプション**で「自動的に録音する」と「文字起こしを自動で開始する」をオンにします（開催者が設定）。

### 2. Entra ID：文字起こしを取得するアプリを登録する（IT 管理者に依頼）
Power Automate から Microsoft Graph を呼ぶためのアプリを登録します。

| 項目 | 設定 |
|---|---|
| API のアクセス許可（アプリケーション） | `OnlineMeetings.Read.All`、`OnlineMeetingTranscript.Read.All`、`Calendars.Read` ＋管理者の同意 |
| クライアントシークレット | 発行し、Power Automate の HTTP アクションで使う |
| アプリケーション アクセス ポリシー | Teams PowerShell で開催者に付与する（下記） |

```powershell
New-CsApplicationAccessPolicy -Identity "Sugiyama-Minutes" -AppIds "<アプリID>" -Description "椙山改修 議事録自動化"
Grant-CsApplicationAccessPolicy -PolicyName "Sugiyama-Minutes" -Identity "<開催者のメールアドレス>"
```

> アプリ登録ができない場合は、下の「方式B（半自動）」で運用できます。

### 3. SharePoint：作業用フォルダを作る
Office Scripts は OneDrive か SharePoint 上のブックにしか実行できないため、作業用フォルダ（例：`椙山改修/_作業用`）を用意します。

### 4. Office Scripts を登録する
Excel on the web で、**自動化 → 新しいスクリプト** を開き、次の2本を作ります。
- `readAgenda`：`office-scripts/readAgenda.ts` の内容を貼り付け
- `fillMinutes`：`office-scripts/fillMinutes.ts` の内容を貼り付け

### 5. AI Builder のプロンプトを作る
Power Automate → AI ハブ → **プロンプト** で新規作成し、`prompts/01_議事録作成プロンプト.md` の本文を貼り付けます。
入力は `議題JSON`・`開催情報`・`前回までの未決事項`・`マニュアル確認項目`・`文字起こし` の5つで、出力は **JSON** です。
`マニュアル確認項目` には、運用マニュアルの確認項目を固定の文章として貼り付けておきます。

### 6. Box AI Hub を作る
`boxai/アシスタント設定.md` の手順どおりに作成します。

### 7. 議事録フォーマット（対応済み）
次の点は `議事録フォーマット_修正版4.xlsx` で対応済みです。今後はこのファイルを議題づくりの元にします。
- 参加者名簿の 現地／WEB チェックボックスを、非表示列のセルにリンクした（現地＝AM列、WEB＝AN列、名簿と同じ行）。スクリプトがそのセルを TRUE にするとチェックが付く。出席者以外のチェックは毎回外す
- 参加者名簿の見出し（G85）を椙山改修の工事名に修正した
- 議題 No.1 の「農灰色」を「濃灰色」に修正した
- AM・AN 列は非表示のままにする（削除や列の挿入をするとリンクがずれる）

未対応：議題No が 1・2・3・5・6・7（4が欠番）。意図したものでなければ振り直す（欠番があってもスクリプトは動く）。

## フローA：議題メール → Box

| # | アクション | 設定 |
|---|---|---|
| 1 | トリガー：Office 365 Outlook「新しいメールが届いたとき (V3)」 | フォルダ＝**送信済みアイテム**、件名フィルター＝`【椙山改修】定例`、添付ファイルあり |
| 2 | Apply to each（添付ファイル） | 拡張子が `.xlsx` のものだけ処理 |
| 3 | Box「ファイルの作成」 | `/椙山改修/定例会議/01_議題/`、名前＝`{開催日}_第{回}回_議題.xlsx` |
| 4 | SharePoint「ファイルの作成」 | `_作業用/{開催日}_第{回}回.xlsx`（フローBが書き込み先に使う） |

**議題メールの件名ルール**：`【椙山改修】定例 第02回 議題（10/2）`
回数と開催日は、件名から「文字列の抽出」で取り出します。

## フローB：会議終了 → 議事録作成

| # | アクション | 設定・ポイント |
|---|---|---|
| 1 | トリガー：Outlook「今後のイベントがまもなく開始されるとき (V3)」 | 定例用の予定表。条件：件名に `椙山` と `定例` を含む |
| 2 | 「待ち時間」 | 終了時刻＋30分まで待つ（文字起こしの生成を待つため） |
| 3 | HTTP：トークン取得 | `POST https://login.microsoftonline.com/{tenant}/oauth2/v2.0/token`（client_credentials、scope=`https://graph.microsoft.com/.default`） |
| 4 | HTTP：会議の参加URLを取得 | `GET /v1.0/users/{開催者}/events/{イベントID}?$select=onlineMeeting` |
| 5 | HTTP：会議IDを取得 | `GET /v1.0/users/{開催者}/onlineMeetings?$filter=JoinWebUrl eq '{joinUrl}'` |
| 6 | HTTP：文字起こしの一覧 | `GET /v1.0/users/{開催者}/onlineMeetings/{会議ID}/transcripts` → 最新の1件 |
| 7 | HTTP：文字起こし本文 | `GET …/transcripts/{ID}/content?$format=text/vtt` |
| 8 | Box「ファイルの作成」 | `02_文字起こし/{開催日}_第{回}回_文字起こし.vtt` |
| 9 | Excel Online「スクリプトの実行」 | 対象＝`_作業用/{開催日}_第{回}回.xlsx`、スクリプト＝`readAgenda` |
| 10 | Box「パスを使用してファイルコンテンツを取得」 | `04_最新状況/最新_未決事項一覧.md`（初回は存在しないので「実行条件の構成」で失敗時も続行し、「なし」を渡す） |
| 11 | AI Builder「プロンプトを実行する」 | 手順9・10・7の結果と開催情報を渡す |
| 12 | 「JSON の解析」 | プロンプトの出力 |
| 13 | Excel Online「スクリプトの実行」 | スクリプト＝`fillMinutes`、`minutesJson`＝手順11の出力文字列。戻り値が `OK` 以外なら手順16で通知 |
| 14 | SharePoint「ファイル コンテンツの取得」→ Box「ファイルの作成」 | `03_議事録/{開催日}_第{回}回_議事録.xlsx` |
| 15 | Box「ファイルの作成」×2 | `03_議事録/…_要約.md`（`markdown`）と、`04_最新状況/最新_未決事項一覧.md`（`open_items_markdown`、**上書き**） |
| 16 | Teams「チャネルにメッセージを投稿」 | 「第◯回 議事録（案）ができました」＋ Box のリンク＋ fillMinutes のログ |

### 方式B（半自動）：アプリを登録できない場合
手順1〜7の代わりに、開催者が会議後に Teams の「レコーディングと文字起こし」から文字起こし（.vtt または .docx）をダウンロードし、Box の `02_文字起こし` に置きます。
フローBのトリガーを **Box「フォルダーにファイルが作成されたとき」** にすれば、手順8以降は同じ内容で動きます。

## 運用ルール
- **議題はこのブックに書く**：議題No の列（E列）に番号、F列以降に本文を書く。結果欄（V列）は空けておく。
- **議事録は「案」として作られる**：担当者が Box 上の xlsx を確認・修正して確定する。修正したら同じ名前で上書きする（Box のバージョン履歴が残る）。
- **話者名を正しく出す**：現地の会議室マイクで話すと、話者がすべて「会議室」になる。発言時に「清水建設の金子です」と名乗る運用にすると、AI が主体を正しく書ける。
- **名簿**：参加者名簿（G列）にない人にはチェックが付かず、Teams の通知にログが出る。新しく参加した人は議題ブックの名簿に追加しておく。
- **結果欄の行数**：議題本文の行数が、そのまま結果を書ける行数になる。結果が長い議題は、議題の下に空行を数行入れておく。

## 動作確認
`samples/sample_ai_output.json` は AI の出力例です。Excel on the web で議題ブックのコピーを開き、`fillMinutes` を実行するときにこの JSON を渡すと、書き込み位置を確認できます。
