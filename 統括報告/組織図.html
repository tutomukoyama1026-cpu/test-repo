運用のきまり

  • 担当どうしが同時に push しないよう、社長が片方の完了を確かめてから次を頼む。
  • 担当は終わると社長にメッセージで知らせる。社長が結果を確かめ、質問があれば小山さんに中継する。
  • 社長経由で届いた小山さんの依頼は、確認なしで作業・push まで進める（増減・チェック2人・議事録・工程は作成時から。図面・計画書リスト担当は 11/1 の小山さんの指示「図面・計画書のチェックも他のたんとうと同じルールにして」でそろえた。課題担当はまだ）。課題担当は社長へ直接返信できないため、完了報告は 椙山改修/作業報告.md に書き、社長が読む。判断が要るものだけ社長に質問する。
  • チェックの指摘で図面・計画書が再提出になるときは、社長が図面担当にも知らせる。
  • 備考に「発注済み」とある製作図、施主確認中のサイン（アイセイ-1）は、期日を過ぎていても緊急項目に入れない。石綿の報告書（報-1）はチェックしない。
  • 朝の報告に Todo を統合（Todo の URL を別に開かなくてよい）。順番は 緊急項目 → Todo → 図面・計画書リスト → 次回定例までにやること → 課題 → 増減 → 今週・来週の工程 → 工程表とのずれ。
  • 各担当の最新の成果物は 成果物/01_社長〜08_工程管理 フォルダに毎朝まとめる（パソコンでは GitHub Desktop で取得）。
